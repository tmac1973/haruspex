# Phase 01 — Loopback preview server

**Depends on:** nothing · **Enables:** the reload watcher (02), the preview
window (03) and everything after

## Goal
A Rust loopback HTTP server that serves one Code session's folder at
`http://127.0.0.1:<port>/<token>/<path>`, and two commands to start and stop
a session's mapping. Nothing in the UI uses it yet; it is testable from Rust
and from `curl`.

## Files touched
- `src-tauri/src/preview/mod.rs` — new module: `PreviewServer` managed state,
  `preview_serve` / `preview_stop` commands, `PreviewServe` struct.
- `src-tauri/src/preview/paths.rs` — new: `resolve(root, url_path)` that maps a
  request path to a file inside the root or refuses it.
- `src-tauri/src/preview/http.rs` — new: the axum router, Host check, headers.
- `src-tauri/src/owner/server.rs` — make `content_type` `pub(crate)` so the
  preview server shares its MIME table, and add `htm`, `jpg`/`jpeg`, `gif`,
  `webp`, `avif`, `woff`, `ttf`, `otf`, `mp3`, `mp4`, `webm`, `txt` (it has
  `html`, `js`, `css`, `json`, `svg`, `png`, `ico`, `woff2`, `wasm` already).
  `urlencoding` is already a dependency; no new crates.
- `src-tauri/src/lib.rs` — `mod preview;`, `.manage(preview::PreviewServer::default())`,
  register the two commands.
- `src/lib/ipc/gen/*` and `src/lib/ipc/commands.ts` — regenerated by
  `./scripts/export-ipc-types.sh`.

## Steps
1. `PreviewServer` holds a `tokio::sync::Mutex<Option<Running>>`, where
   `Running` is the bound port, the axum task's `JoinHandle` with a shutdown
   `oneshot::Sender`, and `HashMap<String /*token*/, Mapping>`. `Mapping` is
   `{ session_id, root: PathBuf /*canonical, non-verbatim*/, served: HashSet<PathBuf> }`.
   A second index `HashMap<session_id, token>` gives each session one token.
2. `preview_serve(session_id: String, root: String, path: String) -> Result<PreviewServe, String>`
   (async), `path` relative to `root` with `/` separators: canonicalise `root` and strip the `\\?\` prefix the way
   `video/paths.rs::plain` does; refuse a root that isn't a directory. If the
   session already has a token, reuse it; else make a 32-hex-char token with
   `ring::rand::SystemRandom` (as `artifact_frame::new_id` does). Start the
   listener on first use: `tokio::net::TcpListener::bind("127.0.0.1:0")`, then
   `axum::serve(...).with_graceful_shutdown(...)` on `tauri::async_runtime`.
   Check `path` with `paths::resolve` (step 4) and that it ends `.html` or
   `.htm`, returning the refusal's message on failure ("Not inside the
   session folder.", "Not found: <path>", "Only .html and .htm files can be
   previewed."). Return
   `PreviewServe { url: "http://127.0.0.1:<port>/<token>/<percent-encoded path>" }`
   (`#[derive(Serialize, TS)] #[ts(export)]`, camelCase). This is the one
   check of the path; the tool and the buttons rely on it.
3. `preview_stop(session_id: String)`: drop that session's mapping; when no
   mapping is left, send shutdown and clear `Running`, so the next serve gets a
   new port.
4. `paths::resolve(root, rest) -> Result<PathBuf, Refusal>` where `rest` is the
   part of the URL path after the token:
   - percent-decode with `urlencoding::decode`; refuse invalid UTF-8, NUL, `\`,
     and a segment that is `..`, starts with `.` (dotfiles, `.git`, `.env`), or
     looks like a drive (`C:`); drop empty and `.` segments;
   - join onto `root`, canonicalise and strip `\\?\`; refuse unless the result
     `starts_with(root)` (this catches symlinks out of the folder);
   - a directory resolves to its `index.html`; a missing file is a 404.
5. `http.rs` router: one `GET` handler on `/{token}/{*rest}` plus `/{token}/`.
   Before anything, check the `Host` header is exactly `127.0.0.1:<port>` or
   `localhost:<port>`, else 421 (DNS-rebinding guard). Unknown token → 404 with
   no detail. On success read the file with `tokio::fs::read`, record the path
   in the mapping's `served` set, and respond with `Content-Type` from
   `owner::server::content_type`, `Cache-Control: no-store`,
   `X-Content-Type-Options: nosniff`, and
   `Content-Security-Policy: frame-ancestors 'self' tauri://localhost http://tauri.localhost`
   plus `http://localhost:1420` under `cfg!(debug_assertions)`. Every other
   method → 405. Files over 64 MiB → 413.
6. A `served_for(session_id) -> Vec<PathBuf>` accessor and a
   `on_served: Option<Box<dyn Fn(&str, &Path) + Send + Sync>>` hook on
   `PreviewServer` (called with session id and path after each successful
   serve), left unset in this phase, for phase 02 to attach to.
7. Run `./scripts/export-ipc-types.sh`.

## Test plan
- `paths.rs` unit tests on a temp dir: a plain file, a nested file, a
  directory → `index.html`, `%2e%2e/`, `..`, `a/../../x`, `\..\`, `C:/x`,
  `/etc/passwd` after decoding, `.git/config`, `.env`, a symlink to a file
  outside the root (unix-only test), an encoded NUL.
- `http.rs` tests that bind a real listener and use `reqwest` (already a dep):
  correct file and MIME, wrong token 404, foreign `Host` 421, `POST` 405, and
  the `Cache-Control`/`frame-ancestors` headers present.
- `preview_serve` refuses `../x.html`, `notes.md` and a missing file with the
  messages above, and returns a URL that `GET`s the file.
- Lifecycle test: serve two sessions → one port, two tokens; stop one → the
  other still serves; stop both → the port is closed (connect fails).
- Windows CI (`windows-ci` label) covers the `\\?\` and drive-letter cases.
