# Phase 09 — Install video models into ComfyUI

**Depends on:** 01, 04, 06, 07, 08 · **Enables:** 10

## Goal

Settings → Video generation installs a family's files into the user's ComfyUI
with Settings → Image's three routes: direct download when the server is on
this machine, ComfyUI-Manager when it runs, or a manual list. Each family shows
its licence, commercial use and VRAM need.

## Files touched

- `src-tauri/src/comfy_models.rs` — `ComfyModelKind`, video sets, new folders.
- `src/lib/ipc/gen/*` — regenerated by `./scripts/export-ipc-types.sh`.
- `src/lib/comfyui/provision.ts` (moved from `src/lib/image/comfyui/provision.ts`) — takes a `missingFiles` function per kind.
- `src/lib/image/comfyui/provision.ts` — re-exports the image wiring from the shared module.
- `src/lib/videogen/comfyui/provision.ts` (new) — video `missingFiles`.
- `src/lib/components/settings/ComfyModels.svelte` — a `kind` prop.
- `src/lib/components/settings/VideoEntryEditor.svelte` — `ComfyModels kind="video"` in the ComfyUI block.
- `src/lib/videogen/comfyui/backend.ts` — the probe's missing-files message names Install.
- Tests: Rust tests in `comfy_models.rs`; `provision.test.ts` for both kinds.

## Steps

1. `comfy_models.rs`:
   - `#[derive(TS)] enum ComfyModelKind { Image, Video }` (snake_case), and a
     `kind` field on `ComfyModelSet`. Every existing set gets `Image`, as does the upscaler.
   - `ComfyFolder` gains `AudioEncoders` (`audio_encoders`). `local_folders`
     treats it as optional, like `upscale_models` and `loras`.
   - Four video sets, each with its files from the official Comfy-Org Hugging
     Face repackaged repos (the files phase 07 and 08 graphs load), sha256 and
     size taken from the Hugging Face file pages:
     `wan22_ti2v_5b`, `wan22_i2v_14b` (both noise models and both lightx2v LoRAs),
     `wan22_s2v` (with the wav2vec2 audio encoder), `ltx23` (model, Gemma text
     encoder, audio VAE). Shared files (`umt5_xxl`, `wan_2.1_vae`) use `shared(...)`.
   - Licence and `commercial_use` from phase 07 and 08's family tables;
     `vram_mb` and `ram_mb` from the peaks phase 07 and 08 wrote in
     `src/lib/videogen/comfyui/templates/README.md`.
   - `comfy_model_catalogue` returns every set; the front end filters by `kind`.
2. Run `./scripts/export-ipc-types.sh` and commit the regenerated types.
3. `src/lib/comfyui/provision.ts`: move the route logic (`chooseRoute`,
   `installDirect`, `installViaManager`, `managerRefusalHint`, `manualList`,
   `MANAGER_TYPE` with `audio_encoders` added) to the shared module. It takes
   `missingFiles(cfg, set)` as an argument. Image passes its current one;
   `src/lib/videogen/comfyui/provision.ts` passes one built on the video
   family table and `WANTED` lists.
4. `ComfyModels.svelte`: `kind: 'image' | 'video'` prop (default `'image'`)
   that filters the sets and picks the matching `missingFiles`. Error and hint
   texts name "Settings → Image" or "Settings → Video generation" by kind.
5. `VideoEntryEditor.svelte`: show `ComfyModels kind="video"` under the ComfyUI
   server block; `onInstalled` re-probes and, when the entry has no model yet,
   chooses the installed family's diffusion model (for Wan 2.2 I2V 14B, the
   high-noise file, the only one `listVideoModels` offers).
6. Phase 07's missing-files probe message gains its second sentence:
   "Settings → Video generation → Install adds them."

## Build gate

`npm run check`, `npm run lint`, `npm run format:check`, `npm run test`;
from `src-tauri/`: `cargo test`, `cargo clippy`, `cargo fmt -- --check`;
`./scripts/export-ipc-types.sh` leaves no diff.

## Test plan

- Rust: every set has files with a sha256 and size; family keys are unique
  across image and video; `local_folders` accepts an answer without `audio_encoders`.
- `provision.test.ts`: the video `missingFiles` finds a missing low-noise model
  and a missing audio encoder; the manager route maps `audio_encoders`.
- By hand, local ComfyUI: Install Wan 2.2 TI2V 5B with no files present; it
  downloads with progress and the entry probes ok.
- By hand, asmodean (not local): the manager route queues the download, or the
  manual list names the files and folders.
- Settings → Image's Install still lists only image sets.

## Commit

`feat(settings): install ComfyUI video models from Settings → Video generation`

## Rollback

Revert the commit and re-run `./scripts/export-ipc-types.sh`. Files already
downloaded stay in the user's ComfyUI and do no harm.
