Does a backgrounded webview keep running?

Remote web chat assumes Haruspex keeps working while its window is minimised. Windows renders it in WebView2 — the same Chromium engine as Edge — and Chromium throttles hidden pages.

Two things are measured separately, because they fail separately: timer cadence (what Chromium clamps first) and whether network requests still complete (what the agent loop actually depends on, since turns are driven by streaming responses, not timers). The network probe chains each request from the previous one's completion rather than from a timer, so a throttled timer cannot make a healthy network look broken.

Run it

  1. Optionally set a label so two runs are easy to tell apart.
  2. Press Start, then minimise the window.
  3. Leave it at least 15 minutes — Chromium's harshest throttling only engages after 5 minutes hidden.
  4. Restore, press Copy result, paste it back.

Second run: with the fix

To check whether Chromium's anti-throttling flags cure it — the same flags Tauri can pass to WebView2 via additionalBrowserArgs — run this in PowerShell from the folder holding this file, then repeat the steps above. One line, because pasted line-continuations break. msedge.exe is not on PATH, hence the full path — and the throwaway profile forces a fresh browser process, without which the flags are silently ignored when Edge is already running. 

& "C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" --disable-background-timer-throttling --disable-backgrounding-occluded-windows --disable-renderer-backgrounding --no-first-run --no-default-browser-check --user-data-dir="$env:TEMP\thtest" "$PWD\webview-throttle-test.html"

If Edge is not at that path, this finds it — also one line: 

& (@("$env:ProgramFiles\Microsoft\Edge\Application\msedge.exe","${env:ProgramFiles(x86)}\Microsoft\Edge\Application\msedge.exe") | Where-Object {Test-Path $_} | Select-Object -First 1) --disable-background-timer-throttling --disable-backgrounding-occluded-windows --disable-renderer-backgrounding --no-first-run --no-default-browser-check --user-data-dir="$env:TEMP\thtest" "$PWD\webview-throttle-test.html"
