Does a backgrounded webview keep running?

Remote web chat assumes Haruspex keeps working while its window is minimised. Windows renders it in WebView2, which is Chromium — the same engine as Edge — and Chromium throttles hidden pages hard. This measures whether it does.

  1. Press Start.
  2. Minimise this window (or cover it completely with another).
  3. Leave it alone for at least 15 minutes. Longer is better — Chromium's harshest throttling only kicks in after 5 minutes hidden.
  4. Restore the window and press Copy result.

Not started.
